## 今日知识点

### 1. 重复事件 + 例外模型

- 默认规则：每周重复的固定课程。
- 例外：某一天的临时变动（停课/调课/换地点）。
- 例外按日期作用域自然过期，下周自动恢复默认，不需要清理代码。

### 2. weekday 编码

- ISO 标准：1=周一 … 7=周日。
- Java 用 `LocalDate.getDayOfWeek().getValue()` 获取。
- `Integer` 表示“没有值”用 null，而不是 0。

### 3. 数据库迁移

- `CREATE TABLE IF NOT EXISTS` 只对新库生效，老库不会自动加列。
- 老库需要 `ALTER TABLE ADD COLUMN`。
- 已经加过的列再次执行会报 duplicate column，要捕获并忽略。
- 本次迁移补 4 列：`start_time`、`end_time`、`weekday`、`weeks`。

### 4. course_overrides 表

- 记录单日临时变动。
- `kind`：`cancel`（停课）或 `move`（调时间/换地点）。
- `course_id` 找不到时允许为 null，变动会被忽略。

### 5. coursesOn(date)

- 按 weekday 查默认课程。
- 再叠加当天的 overrides：
  - cancel：移除该课程
  - move：替换时间/地点
- 返回当天的有效课程列表。

### 6. YAGNI

- `weeks` 字段先存不筛。
- 因为还没有学期起始日期，无法算当前第几周。
- 现在不做未来才需要的功能。
