## 今日知识点

### 1. 为什么要标注周次

- 让 LLM 回答“今天有什么课”时能说出“今天是第几周”。
- 否则它只知道课程列表，不知道当前周次。

### 2. 四种状态

- 未设置学期：提示用户如何设置
- 未开学（w=0）：提示学期开始日期
- 学期内：今天是第 N 周（共 M 周）
- 假期（w > totalWeeks）：提示本学期已结束

### 3. weekOf 的返回值

- 未设置学期返回 `-1`
- 不是 `Optional.empty()`
- 所以判断时要用：
  ```java
  weekOpt.isEmpty() || weekOpt.get() == -1
  ```

### 4. todaySection 的变化

- 原来只返回课程列表
- 现在返回：`周次说明 + "\n" + 课程列表`

## 文件与方法链路

```text
todaySection()
   ↓ repo.weekOf(LocalDate.now())
当前周状态
   ↓ 生成 weekLine
未设置 / 未开学 / 第 N 周 / 假期
   ↓ repo.coursesOn(LocalDate.now())
今日课程
   ↓
weekLine + "\n" + courses
```

## 今天踩坑记录

- `questionFlowReturnsLlmAnswer` / `questionStreamEmitsDeltas` / `todayCourseIncludedInQuestionPrompt` 报 `NoSuchElementException`。
- 原因：未设置学期时 `weekOf` 返回 `-1`，但代码用 `weekOpt.isEmpty()` 判断，导致走进 `semester().orElseThrow()` 抛异常。
- 修复：判断条件加上 `weekOpt.get() == -1`。
