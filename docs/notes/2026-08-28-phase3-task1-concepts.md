## 今日知识点

### 1. POI 与 EasyExcel

- POI：Apache 提供的底层 Excel 读写库，代码繁琐。
- EasyExcel：阿里在 POI 之上的封装，更简单、内存占用更低。
- 国内招聘 JD 常见。

### 2. 回调式读取

- EasyExcel 不是一次性读完全部行。
- 每读一行回调一次处理方法。
- 大文件不会一次性占满内存。
- 和 SSE 流式是同一个思想：边到边处理。

### 3. multipart/form-data

- 浏览器上传文件时使用的 HTTP 编码方式。
- 可以同时包含普通字段和文件内容。
- Spring 用 `MultipartFile` 接收上传文件。

### 4. @Scheduled + cron

- `@Scheduled` 让 Spring 定时执行方法。
- cron 表达式：`秒 分 时 日 月 周`
- `0 0 7 * * ?` = 每天早上 7:00:00 执行。

### 5. 幂等 + 懒生成兜底

- 定时任务依赖电脑开机，不可靠。
- 懒生成：访问页面时如果当天报告不存在，现场生成。
- 两条路径共用同一份生成逻辑。

### 6. 抽取逻辑复用

- 聊天录入和 Excel 导入流程相同：
  ```text
  文本 → LLM 抽取 → 校验 → 入库 → 失败兜底
  ```
- 抽成 `ExtractionEngine`，两处共用。
- 避免重复代码，修改只改一处。
