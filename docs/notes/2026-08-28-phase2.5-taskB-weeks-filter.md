## 今日知识点

### 1. 周次表达语法

- `"1-16"`：第 1 到 16 周都上
- `"1-8,10-16"`：第 1-8 周 和 第 10-16 周上
- `"5"`：只有第 5 周上
- `"1-16单"`：只上单数周（1、3、5…）
- `"1-16双"`：只上双数周（2、4、6…）
- 空字符串或 null：全程上课

### 2. 过滤规则

- weeks 为空/null → 不过滤
- 有值 → 当前周落在任一区间才保留
- 学期未设置 → 不过滤，保持旧行为
- 未开学/假期 → 没有默认课程

### 3. WeekRanges.contains

- 作用：判断某个周次是否落在表达式范围内
- 先按逗号分段
- 处理“单/双”后缀
- 解析区间或单周
- `oddOnly` → 单数周（`week % 2 == 1`）
- `evenOnly` → 双数周（`week % 2 == 0`）

### 4. coursesOn 加过滤

- 额外用 `Map<Long, String> courseWeeks` 存“课程 id → weeks”
- 因为 `CourseOccurrence` 没有 weeks 字段
- `weekOpt > totalWeeks` → 假期，直接返回空列表
- 学期内按 `WeekRanges.contains` 过滤，匹配才保留
- 过滤后再叠加 overrides

## 今天答错的点 / 追问重点

1. **`WeekRanges` 类 `final`/`private` 的原因**：
   - `final` 是防止被继承
   - `private` 构造是防止外部 `new`
2. **`oddOnly` 是确保双数？** 错。`oddOnly` 是确保**单数**；`evenOnly` 才是双数。
3. **体育的 weeks 是 `"1-16"`？** 错。体育的 weeks 是 `null`，表示全程上课。
4. **`courseWeeks` 存“本周课程”？** 不准确。它存每门课的 weeks 表达式。
